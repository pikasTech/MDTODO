# Execution Modes

## Supported modes

The extension currently supports three execution modes:

- `claude`
- `codex`
- `opencode`

The selected mode is stored per workspace in:

```text
.vscode/mdtodo/settings.json
```

Example:

```json
{
  "executionMode": "codex"
}
```

## Generated command shapes

### Claude

```bash
claude --dangerously-skip-permissions execute "TODO.md 中的 R1 任务"
```

### Codex

```bash
codex --dangerously-bypass-approvals-and-sandbox "请执行 TODO.md 中的 R1 任务"
```

### OpenCode

```bash
opencode --model minimax/MiniMax-M2.5 --prompt "TODO.md 中的 R1 任务"
```

## Runtime behavior

When a task is executed:

- the extension resolves the workspace root
- uses a workspace-relative TODO path when possible
- records a task-execution log entry
- launches the configured CLI in a new terminal window

Copyable commands are generated by `src/providers/managers/commandGenerator.ts`.

Actual terminal launch is handled by `src/services/claudeService.ts`.

## OpenCode-specific note

OpenCode model listing is performed via `opencode models`, and the selected model is stored alongside `executionMode`.

## Distilled evolution outline

Execution support evolved in order:

- Claude Code integration first
- OpenCode routing and model support later
- Codex support added after the multi-executor settings flow already existed
