# Documentation

This repository follows the `docs-spec` pattern:

- `CLAUDE.md`: top-level project index
- `docs/reference/`: stable reference docs distilled from project history
- `docs/details/`: immutable process reports and task records
- `docs/plans/`: one-off plans that may later be distilled into reference docs
- `docs/*.md`: original MDTODO process documents kept as historical sources

Recommended reading order:

1. `CLAUDE.md`
2. `docs/reference/overview.md`
3. `docs/reference/extension-entrypoints.md`
4. `docs/reference/task-markdown-format.md`
5. `docs/reference/execution-modes.md`
6. `docs/reference/cli-and-skill.md`
7. `docs/reference/build-and-release.md`
8. `docs/reference/process-distillation.md`
